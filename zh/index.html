平台

一个共享维修工具的完整平台。

一个门店网络共享加密狗和手机所需的一切，井然有序、责任分明。

远程 USB 与 ADB

原始 USB 加密狗和通过 ADB 的手机，安全隧道传输。在技术员那里显示为本地设备；他的工具直接在其上运行。

访问控制

9 位 ID，每次连接都需批准。手机和 USB 分别授权。谁、访问什么、多久，由你决定。

◱

带积分的群组

把同行组织成带积分经济的群组：1 积分 = 1 分钟。使用者付费，拥有者赚取。

↻

flash-safe 重连

刷机中途断网不会毁掉会话：它会自动恢复，设备保持挂载。

⚙

常驻服务

作为 Windows 服务（SYSTEM）运行，开机自启，无需打开会话即可保持共享有效。

▤

队列与审计

带位置和预计时间的 FIFO 队列、每轮限额，以及完整使用日志：谁、什么、何时、多久。

安全与控制

访问始终在你的掌控之中。

流量在传输中加密，每个连接都要经过拥有者批准。每一轮都被记录，任何技术员都可被即时封禁。

  • 每次连接都需批准未经拥有者明确同意，任何人都无法访问设备。
  • 完整审计使用与操作的日志 —— 包括通过 AI（MCP）的操作。
  • 端口级隔离端口白名单，防止未经授权的访问（anti-SSRF 保护）。

工作原理

从共享到工作，只需三步。

步骤 01

共享

接上加密狗或手机，通过对方 ID 提供给某位同行，或提供给整个群组。

步骤 02

批准

技术员用你的 ID 请求访问。你收到请求并批准 —— 一次或永久。

步骤 03

工作

设备在技术员那里显示为本地设备。结束后自动断开，本轮以积分结算。
